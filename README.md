## Getting Started

1. Read `.aos/CHARTER.md`
2. Define your project in `docs/blueprint/ARCHITECTURE_BLUEPRINT.md`
3. Define phases in `docs/plan/PHASE_PLAN.md`
4. Add verify gates in `verify/` and register in `.aos/GATES.md`
5. Build phase by phase.

## Verify
