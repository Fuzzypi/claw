# AOS Governance Canon

This document is the root index for AOS governance.

## Canonical Artifacts

- Lawset (single source of truth): `governance/laws/LAWSET.md`
- Agent rules and prompts: `governance/agents/`
- Skills: `governance/skills/`

If there is a conflict, the LAWSET is authoritative.

## Enforcement

All work must pass verify gates before a phase is considered complete.
Gates define correctness. Passing gates is the definition of compliance.

## Authority and Change Control

- Laws change only via explicit edits to `governance/laws/LAWSET.md`.
- Governance changes require corresponding verify gates or updates to existing gates.
